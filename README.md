# JEE Main Test Series Platform

A digital examination platform designed to help JEE Main aspirants prepare through structured mock tests, subject-wise assessments, and performance tracking.

## Project Overview

JEE Preview Site is a web-based examination platform designed to provide students, faculty, and administrators with a structured environment for managing and conducting JEE Main test series.

## Key Features

- **Student Portal** – Student registration, login, dashboard, and account management.
- **Mock Test Management** – Scheduled Part Tests and Grand Tests.
- **Question Management** – Faculty question entry, review, and admin approval.
- **Examination Interface** – Timed tests with question navigation and answer saving.
- **Performance Analysis** – Test reports, scores, rankings, and subject-wise progress.
- **Admin Dashboard** – User roles, student management, and platform administration.
- **Question Paper Export** – Export question papers to Excel, Word, and PDF.

## Technology Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Supabase (PostgreSQL and Authentication)

## Project Structure

- `app/` – Application pages, routes, and server actions
- `components/` – Reusable UI components
- `lib/` – Application utilities and service integrations
- `public/` – Static assets
- `scripts/` – Project scripts and tests
- `supabase/` – Database migrations and seed files

## Project Status

The project includes the initial platform, authentication, role-based areas, question-paper management, review workflows, and scheduled test configuration.

Additional examination and reporting capabilities are documented in the project README.
